BANNIÈRES DE LA PAGE D'ACCUEIL
==============================

Déposez vos images dans ce dossier, avec exactement ces noms (ou changez les noms dans lib/shop/banners.ts) :

  slide-1-bureau.webp  2000 x 667 px   ordinateur   (format 3:1 ; la bannière famille/cuisine est déjà installée)
  slide-1-mobile.jpg   1080 x 540 px   mobile (facultatif : sans lui, le fichier ordinateur est utilisé)
  slide-2-bureau.jpg   2172 x 274 px
  slide-2-mobile.jpg   1080 x 540 px
  slide-3-bureau.jpg   2172 x 274 px
  slide-3-mobile.jpg   1080 x 540 px

Pour ajouter d autres bannières (3 à 5 conseillées) : copiez le modèle en commentaire dans lib/shop/banners.ts.
Tant qu'une image n'existe pas, un bandeau de texte s'affiche à sa place.
Format conseillé : JPG, moins de 300 Ko par image.
